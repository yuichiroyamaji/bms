# Cross-cutting specs

Initiatives that **span domains** (frontend + backend + infra) live here.

| Kind | Path |
|---|---|
| Cross-cutting | `docs/specs/<initiative>/{requirements,design,test-cases,tasks}.md` |
| One feature | `<domain>/src/features/<feature>/docs/` (e.g. `frontend/src/features/<feature>/docs/`) |
